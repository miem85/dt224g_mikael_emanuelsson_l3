# Norrgläntan

## Om projektet

Detta projekt är skapat som en del av Laboration 3 i kursen
Introduktion till webbutveckling med HTML, CSS och JavaScript, DT224G.

Uppgiften går ut på att skapa en responsiv startsida för den fiktiva
naturdestinationen Norrgläntan utifrån en given wireframe och en egen
mockup skapad i Figma.

## Teknik

* HTML5
* CSS
* Flexbox
* CSS Grid
* Media queries
* Mobile first

## Funktioner

Webbplatsen innehåller bland annat:

* Responsiv layout för mobil och desktop
* Navigationsmeny
* Hero-sektion
* Aktivitetskort
* Call-to-action-sektion
* Responsiv footer

## Tillgänglighet

Webbplatsen använder semantisk HTML, alternativtexter för bilder och
synlig fokusmarkering för länkar och knappar.
